# Локальные runbook

Каталог runbook находится в постоянном Docker volume по пути
`/srv/app/data/runbooks`. Его можно заполнить Markdown-файлами через Docker
volume или локальный Docker Desktop UI. Остановка и обновление контейнера не
удаляют каталог.

Пример файла `billing-rollback.md`:

```markdown
# Billing rollback
service: billing-service
tags: rollback, incident

1. Зафиксировать время начала инцидента.
2. Найти предыдущую стабильную версию.
3. Выполнить откат согласно процедуре команды.
```

Поддерживаются только прямые дочерние файлы с расширением `.md`, в UTF-8 и
размером до 1 МБ. Символические ссылки, вложенные каталоги и другие форматы
игнорируются. Идентификаторы, которые получает агент, не раскрывают путь к
файлу на хосте.

Пока каталог пуст, встроенный сервер знаний работает в явно обозначенном
demo-режиме. Когда появится хотя бы один корректный файл, используются только
локальные runbook — демонстрационные материалы не подмешиваются.
