# Приватность

AI Operations Agent — локальное приложение. Оно работает на компьютере пользователя и по
умолчанию не отправляет наружу код, операционные данные или историю расследований.

## Что хранится локально

- история расследований, трассировки и подтверждения — в SQLite на постоянном volume;
- настройки подключений и выбранный репозиторий;
- токен GitHub (зашифрован) и ключ шифрования отдельным файлом;
- локальные Markdown-runbook.

## Какие данные уходят наружу

Только по явным запросам к подключённым системам:

- GitHub API — чтение выбранного репозитория (коммиты, pull requests, deployments, issues)
  и создание issue только после подтверждения;
- Prometheus — read-only запросы метрик по указанному адресу;
- локальная Ollama — на том же компьютере.

Скрытой телеметрии нет. Код и данные не отправляются внешнему LLM-провайдеру: модель
запускается локально.

## Диагностика и поддержка

Диагностический отчёт (`./manage.sh report`) формируется с маскированием токенов, паролей и
учётных данных в строках подключения, поэтому его можно приложить к обращению.

## Удаление данных

Полное удаление — только явной командой:

```bash
./manage.sh destroy --delete-data
```

Остановка и обновление данные сохраняют.
